OVERLEAF CODEX

设置

连接 Chrome 扩展与本机 Codex。

本机桥接

桥接服务只在你的电脑上运行。

LOCAL

仅允许 127.0.0.1 或 localhost。

运行 npm run show-token 获取。

默认保存在 Codex sessions 目录下的专用子目录。

Overleaf 完整项目会同步到这个本地目录。

模型和推理强度 在 Overleaf 聊天输入器中选择并自动保存

使用方法

保持本机桥接运行，再从 Overleaf 唤起 Codex。

  1. 1
    在项目目录运行 npm start。
  2. 2
    粘贴终端显示的 Token，然后保存并测试连接。
  3. 3
    在 Overleaf 源码编辑器选中文字。
  4. 4
    按 ⌘ ⇧ K（macOS）或 Ctrl ⇧ K（Windows/Linux）打开。
