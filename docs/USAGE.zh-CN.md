# 使用指南

[English](USAGE.md)

## 基本流程

1. 使用 `npm start` 启动桥接。
2. 在 Overleaf 中打开项目并切换到源码编辑器。
3. 按 `Command/Ctrl + Shift + K` 打开或聚焦 Overleaf Codex。
4. 输入问题，可选添加文件/行号引用或 `@插件`。
5. 查看 Codex 回复、工具活动和可能出现的修改候选。
6. 检查差异后再应用候选。

打开聊天窗口不会自动捕获当前选区。

## 添加引用

在 Overleaf 源码编辑器中选中文字，或把光标停在某一行，然后按：

- macOS：`Command + Shift + I`
- Windows/Linux：`Ctrl + Shift + I`

每次操作会新增一个引用卡片，其中包含项目相对路径和从 1 开始的行号范围。
可以重复使用快捷键，引用多个文件或同一文件中的多个范围。

引用会保留在输入框上方，供后续追问继续使用，直到手动移除或新建对话。通过
`+` 菜单显式添加的整文件属于单轮重点上下文，发送成功后会自动清空。

引用只代表上下文，不代表修改指令。只有当前消息明确要求修改时，Codex 才应
返回替换候选。

## 聊天控件

- `Enter`：发送
- `Shift + Enter`：换行
- 向上箭头按钮：发送当前消息
- 方形停止按钮：输入框为空时中断当前 turn
- 历史图标：打开按项目分组的聊天历史
- 铅笔图标：新建对话
- 齿轮图标：打开桥接、目录和快捷键设置
- 最大化图标：最大化或还原
- 拖动标题栏：移动窗口
- 拖动边缘或四角：调整窗口大小

## 模型和推理强度

使用输入器右下角的选择器。扩展会从本机 Codex App Server 读取当前可见模型，
以及每个模型支持的推理强度。

在 turn 执行期间修改选择器，只会影响下一轮，不会改变已经运行的 turn。

## 使用 `@` 插件

在输入框中键入 `@`，搜索本机已经安装并启用的 Codex 插件。选择插件后再描述
任务。

扩展本身不负责安装、启用或登录插件。请在受支持的 Codex 界面完成这些操作，
然后在 Overleaf Codex 中刷新插件列表。修改插件后可能需要重启桥接。

插件工具可能请求：

- 执行命令审批；
- 权限变更；
- OAuth 或登录操作；
- 结构化或自由文本输入。

请逐项检查。插件可能把相关项目内容发送到其连接的外部服务。

## 项目同步

项目第一次发送时会建立完整本地镜像，后续同步使用 Overleaf 历史版本，并只在
需要时下载变化 blob。

当前流程：

```text
编辑停止约 1.5 秒
        ↓
后台静默预同步
        ↓
发送消息或显式 Steer
        ↓
最终 flush + 非等待式版本探测
        ↓
仅在远端版本更新时读取并应用增量
        ↓
以经过校验的本地项目镜像作为 cwd 启动 Codex
```

如果最终同步期间项目继续变化，扩展会重试，直到编辑代数稳定。它不会悄悄
使用过期或未经验证的项目镜像。

## 在运行中使用 Steer

Codex 工作期间发送的新消息会显示为待发送卡片。

- 点击 **Steer**：先同步最新项目，然后把消息注入当前 turn。
- 保持待发送：当前 turn 完成后自动作为新一轮消息发送。
- 删除卡片：放弃这条待发送消息。

显式 Steer 在调用 `turn/steer` 前一定会执行最终项目校验。

## 阅读回复

助手消息支持：

- Markdown 标题、列表、链接、代码和表格；
- `$...$` 或 `\\(...\\)` 行内公式；
- `$$...$$` 或 `\\[...\\]` 展示公式；
- 流式推理摘要和 commentary；
- 工具与本机命令状态；
- 审批和输入卡片。

模型输出中的原始 HTML 不会直接渲染。

## 修改候选

当你明确要求 Codex 修改引用文字时，它可以返回一个或多个候选。每个候选均可：

- **查看差异**：查看词级变化；
- **复制**：复制替换文字；
- **应用到 Overleaf**：更新对应引用范围；
- **撤销应用**：恢复应用前的内容。

存在多个引用时，候选会按文件和行号范围分组。

应用或撤销前，扩展会检查预期文字和附近锚点。如果你或协作者已经修改目标，
操作会被拒绝，不会覆盖较新的内容。

## 历史会话

历史面板按 Overleaf 项目分组：

- 当前项目排在最前。
- 可以打开以前的对话查看或继续。
- 其他项目的对话在打开对应项目之前只能查看。
- 删除操作需要明确确认，并且不可恢复。
- 打开或收起历史面板不会中断正在运行的 Codex turn。

这些历史属于扩展自己的本地记录，不会出现在 Codex App 的普通历史列表中。

## 设置

聊天窗口内的设置可以管理：

- 桥接地址和 Token；
- 聊天历史目录；
- 项目镜像目录；
- Chrome 快捷键管理入口。

切换数据目录时会复制已有数据，并把原目录作为备份保留。

## 示例提示词

只分析、不修改：

```text
解释两个引用公式之间的关系，不要修改文件。
```

检查章节：

```text
检查引用章节是否存在缺少依据的主张和 LaTeX 问题。先报告发现，除非我明确要求，否则不要改写。
```

请求多个版本：

```text
分别为每段引用提供“精简”和“正式”两个版本。保留全部 LaTeX 命令、引用、label 和数值主张。
```

询问整个项目：

```text
检查整个项目，列出所有定义后从未被引用的公式 label。
```

使用插件：

```text
@插件名称 按该插件的工作流处理引用章节。
```

## 安全提醒

- 应用前先查看差异。
- 不要在公开 Issue 中附带桥接 Token、Overleaf Cookie 或私有项目内容。
- 在机密项目中使用插件前，先检查插件的数据处理方式。
- 保持桥接只绑定本机回环地址，不要把 `47831` 端口暴露到网络。
- 修改存储目录前，备份重要项目和聊天历史。
